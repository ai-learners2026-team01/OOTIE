## 🛠️ 1. 準備工作 (Prerequisites)

在進行人工驗收之前，請確保本地開發環境已成功啟動。

```bash
# 1. 安裝套件（若尚未安裝）
npm install

# 2. 啟動 Vite 本機開發伺服器
npm run dev
```

啟動完成後，在瀏覽器中開啟本機網址（預設為 `http://localhost:5173/`）。

## 📋 2. 人工驗收項目與操作步驟

### 驗收項目 1：個人資料與大頭貼上傳/裁切 (Profile & Avatar Upload/Crop)

- **測試目標**：驗證個人檔案資料可編輯，大頭貼支援檔案上傳、即時縮放與位移調整，並能精準裁切產生 320x320 圖片並更新全站頭像。
- **操作步驟**：
  1. 點擊側邊選單或頂部導覽列進入 **「個人檔案」** 頁面。
  2. 點擊 **「編輯資料」** 按鈕開啟編輯彈窗。
  3. 修改「姓名」、「帳號 ID」（若未輸入 `@` 儲存時自動補上）、「頭像縮寫」與「個人簡介」。
  4. 點擊「上傳大頭貼」，選擇電腦中的照片（JPEG / PNG / WebP）。
  5. 上傳後出現「照片調整」控制區塊：
     - 拖拽 **縮放滑桿**（1.0x ~ 2.5x），確認圖片放大/縮小效果。
     - 點擊 **方向按鈕（`←` `↑` `→` `↓`）**，確認圖片在圓形外框中的位移調整。
  6. 點擊 **「儲存資料」**。
- **預期結果**：
  - 個人檔案頁面大頭貼更新為裁切後的圖片。
  - 頂部導覽列 (Topbar) 右上角大頭貼亦同步顯示裁切圖片。
  - Toast 彈出提示：`個人資料已更新`。

---

### 驗收項目 2：公開衣櫥設定 (Public Closet Toggle)

- **測試目標**：驗證公開衣櫥狀態可以順暢切換，並保存在狀態中。
- **操作步驟**：
  1. 在「個人檔案」頁面找到 **「衣櫥設定」** 區塊。
  2. 點擊「公開我的衣櫥」右側的 **切換開關 (Switch)**。
  3. 再次點擊開關切換回原狀態。
- **預期結果**：
  - 開關顯示 Sage 綠色（開啟）或灰色（關閉）之視覺狀態。
  - 開啟時跳出 Toast：`衣櫥已公開`。
  - 關閉時跳出 Toast：`衣櫥已設為私人`。

---

### 驗收項目 3：個人 OOTD 管理（新增、編輯、刪除）

- **測試目標**：驗證個人 OOTD 穿搭紀錄的新增、編輯、刪除與卡片即時渲染。
- **操作步驟 A (新增 OOTD)**：
  1. 點擊「個人檔案」頁面的 **「＋ 發布 OOTD」** 按鈕開啟彈窗。
  2. 選擇上傳一張穿搭照片。
  3. 輸入 Caption 穿搭說明與 Hashtags（例如：`#minimal #dailylook`）。
  4. 在單品列表中勾選 1~2 件標註單品。
  5. 點擊 **「發布穿搭」**。
- **預期結果 A**：
  - 下方「我的 OOTD」區塊立即渲染新卡片，包含照片、 Caption、Hashtags、穿搭單品標註與發布日期。
  - 彈出 Toast 提示：`OOTD 已發布`。

- **操作步驟 B (編輯 OOTD)**：
  1. 在剛發布的 OOTD 卡片右下角，點擊 **「編輯」** 按鈕。
  2. 確認彈窗標題變更為「編輯 OOTD」，舊資料（照片、 Caption、Hashtags、單品）自動填入。
  3. 修改 Caption 文字，點擊 **「儲存修改」**。
- **預期結果 B**：
  - 卡片內容即時更新為修改後的說明文字。
  - 彈出 Toast 提示：`OOTD 修改已儲存`。

- **操作步驟 C (刪除 OOTD)**：
  1. 在卡片右下角點擊紅色 **「刪除」** 按鈕。
  2. 在瀏覽器確認彈窗（`確定要刪除這篇 OOTD 嗎？`）點擊確定。
- **預期結果 C**：
  - 該篇 OOTD 自個人頁面列表中移除。
  - 彈出 Toast 提示：`OOTD 已刪除`。

---

### 驗收項目 4：OOTD 分享連結與單篇檢視頁面 (Share Link & Single OOTD Route)

- **測試目標**：驗證單篇 OOTD 連結複製與獨立分享路由頁面。
- **操作步驟**：
  1. 點擊任意 OOTD 卡片上的 **「分享連結」** 按鈕。
  2. 點擊 OOTD 卡片的 **圖片連結**（或在瀏覽器網址列手動輸入例如 `http://localhost:5173/#/ootd/post-01`）。
  3. 在單篇 OOTD 檢視頁面查看內容，點擊 **「← 返回個人檔案」**。
- **預期結果**：
  - 點擊分享時彈出 Toast 提示：`貼文連結已複製`（或調用系統原生分享）。
  - 成功進入 `/ootd/:id` 路由頁面，完整呈現該篇 OOTD 的滿版照片、說明、Hashtags 與標註單品。
  - 點擊返回按鈕可順暢跳轉回個人檔案頁面。
