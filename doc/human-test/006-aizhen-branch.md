# OOTie 人工驗收指南：legacy/aizhen 功能整合 (衣櫥統計圖表、年度 No.1 報告、冷宮衣物檢測與出清、五大色系階層篩選、CPW 排行與 SOS 穿搭求救聯動)

> **文件版本**：1.0.0  
> **建立日期**：2026-09-26  
> **測試對象**：`legacy/aizhen` 分支功能（衣櫥統計與圖表視覺化、年度 No.1 穿搭報告、冷宮衣物檢測與出清標記、五大色系與二級顏色階層篩選、每次穿著成本 CPW 排行、百搭戰力榜、愛用品牌捷徑與 Style SOS 困擾單品自動帶入）重構至 Vue 3 + Pinia + Vue Router 專案之功能驗收

## 🛠️ 1. 準備工作 (Prerequisites)

在進行人工驗收之前，請確保本地環境已安裝依賴並啟動開發伺服器。

```bash
# 1. 安裝套件（包含 chart.js 等依賴）
npm install

# 2. 啟動 Vite 本機開發伺服器
npm run dev
```

啟動完成後，開啟瀏覽器瀏覽 `http://localhost:5173/`。

### 驗收項目 3：年度 No.1 報告與穿搭名言 (`StatsView.vue`)

- **測試目標**：驗證年度穿搭總結報告可依購入與穿著年份動態切換，並產生 4 項 No.1 指標與個人化名言。
- **操作步驟**：
  1. 於衣櫥統計頁面，查看「年度 No.1 報告」卡片。
  2. 點擊年度下拉選單（例如 `2026 年`、`2025 年`、`2024 年`），觀察表格內容即時切換。
  3. 檢視 4 項統計項目與數據佐證：
     - 🏆 **年度最愛顏色**：顯示購入最多的主色與件數佐證。
     - 🏆 **年度最愛風格**：顯示購入最多的風格與件數佐證。
     - 🏆 **年度最常穿單品**：顯示該年最後穿著且次數最高之單品名稱與穿著次數。
     - 🏆 **年度最愛品牌**：顯示該年購入最多次之品牌名稱與件數。
  4. 檢查下方名言區塊（例如：`「你 2026 年最常買...」`）。
  5. 若該年購入單品少於 3 件，驗證會出現警告提示 `⚠️ 提醒：XXXX 年購入單品少於 3 件，統計僅供參考。`。

### 驗收項目 4：三大榜單（百搭神器、CP 值排行、冷宮清單）(`StatsView.vue`)

- **測試目標**：驗證百搭神器 Top 5、最划算單品（CPW）、冷宮衣物清單的排序與展示。
- **操作步驟**：
  1. 向下滾動統計頁面，檢視 **「我的百搭神器（戰力榜 Top 5）」**：
     - 排序為 `wear_count` 降冪（穿著次數最多者在最前）。
     - 第 1 名帶有冠軍金色皇冠徽章 `♛` 與卡片凸顯樣式 (`.is-champion`)。
  2. 檢視 **「最划算單品（衣櫃 CP 值排行）」**：
     - 依每次穿著成本 $\text{CPW} = \frac{\text{購買價格}}{\max(\text{穿著次數}, 1)}$ 由低到高排序。
     - 每張卡片顯示：`這件你穿了 X 次，平均穿一次只要 X 元！` 與 `購買價格 X 元`。
     - 若無填寫價格之單品，呈現前往衣櫥填寫價格的導引連結。
  3. 檢視 **「冷宮衣物排名（完整清單）」**：
     - 呈現所有未穿 > 90 天或穿著次數 < 2 次的單品。
     - 顯示 `已經 X 天沒穿囉！` 或 `你從來沒穿過耶！`。
- **預期結果**：
  - 三大榜單計算正確，橫向滾動順暢，金銀銅徽章視覺分明。

### 驗收項目 5：我的衣櫥「冷宮衣物提醒」與出清/求救互動 (`ClosetView.vue`)

- **測試目標**：驗證衣櫥頁面頂部的冷宮提醒橫幅、出清標記與求救連動。
- **操作步驟**：
  1. 點擊側欄「我的衣櫥」(`/closet`)。
  2. 觀察頁面頂部的 **「冷宮衣物提醒 (Closet check-in)」** 橫幅。
  3. 右上角顯示 `X 件需要關心`，下方列出前 3 件冷宮單品卡片。
  4. 點擊冷宮卡片上的 **「標記為考慮出清」** 按鈕：
     - 按鈕文字立即變更為 `已標記待出清` 並呈現鎖定 disabled 狀態。
     - 下方衣櫥列表該單品標題右側會即時加上紅褐色 `[待出清]` 標籤。
     - 彈出 Toast 提示「已標記為考慮出清」。
  5. 點擊冷宮卡片上的 **「丟到 SOS 求救」** 按鈕：
     - 頁面自動跳轉至 `/sos?item_id=...`。
     - 自動開啟「請衣友幫忙搭配」Modal 視窗，並帶入該單品名稱至標題與說明，且「已帶入單品」脈絡正確呈現。
  6. 當冷宮單品超過 3 件時，橫幅下方顯示 **「查看完整冷宮排名 →」** 連結，點擊可直接跳轉至 `/stats`。
- **預期結果**：
  - 冷宮判定與提醒即時生效，出清標記與求救導航完整連通。

### 驗收項目 6：五大色系與二級顏色階層式複合篩選 (`ClosetView.vue`)

- **測試目標**：驗證衣櫥工具列的色系與顏色階層式篩選互動。
- **操作步驟**：
  1. 在衣櫥頁面工具列，點擊 **「色系／顏色」** 下拉按鈕。
  2. 彈出色系選單（無彩色系、大地色系、清甜暖色系、藍綠冷色系、紫紅神秘系）。
  3. 點選 **「大地色系」**：
     - 選單下方動態展開主要顏色按鈕：「卡其色」、「奶茶色」、「棕色」。
     - 列表即時過濾出屬於大地色系的單品。
  4. 點選二級顏色中的 **「奶茶色」**：
     - 列表進一步精確篩選出奶茶色單品。
     - 觸發按鈕標籤更新為 `奶茶色`。
  5. 同時搭配選擇「分類」（如「包款」）或「季節」（如「四季」），驗證多條件複合交集篩選正確。
  6. 點擊「清除篩選」，驗證色系、顏色與所有條件皆還原預設狀態。
- **預期結果**：
  - 色系二級聯動互動順暢，色票與多條件複合篩選皆精確無誤。

### 驗收項目 7：單品詳情與表單（品牌捷徑、色系自動帶入、價格驗證）(`ItemDetailModal.vue`, `ItemFormModal.vue`)

- **測試目標**：驗證單品詳情 Modal 顯示 CPW 與價格，以及新增/編輯表單的愛用品牌捷徑與色系自動聯動。
- **操作步驟**：
  1. 於衣櫥點擊任一單品卡片開啟 **單品詳情 Modal**：
     - 欄位包含：分類、色系、主要顏色、品牌、風格、適合季節、版型、**價格**、**每次穿著成本 (CPW)**、穿著次數、上次穿著。
     - 底部按鈕包含：「丟到 SOS 求救」、「標記為考慮出清」、「編輯」、「刪除」。
  2. 點擊「＋ 新增單品」開啟 **新增單品 Modal**：
     - 在「品牌」欄位旁，觀察有 **「Uniqlo」、「ZARA」、「COS」、「Nike」...** 等愛用品牌快速標籤。
     - 點擊標籤（如 `COS`），品牌輸入框自動填入 `COS`。
     - 在「主要顏色」選擇 `丹寧藍`，觀察「色系」輸入框自動聯動填入 `藍綠冷色系`。
     - 在「購買價格」輸入 `2500`。若輸入負數或 0，送出時會提示 `購買價格請輸入正數`。
  3. 上傳照片並儲存，驗證新單品成功加入衣櫥，且統計頁面數據同步即時更新。
- **預期結果**：
  - 單品詳情數據齊全，表單快捷鍵與色系聯動提升輸入體驗，價格驗證健全。
