> **建立日期**：2026-09-26  
> **測試對象**：`legacy/Ian` 分支功能（穿搭商品願望清單/書籤、橫式雙欄大圖表單、商品詳情彈窗、批次管理刪除、防重複收藏偵測、Chrome 智慧擷取擴充功能、手機快速選單整合、Supabase `ootie_bookmarks` 資料表與 RLS 權限）重構至 **Vue 3 + Pinia + Vue Router + Vite** 專案之功能驗收

### 安裝 Chrome 擴充功能套件：
1. 開啟 Google Chrome 瀏覽器。
2. 於網址列輸入 `chrome://extensions/` 並進入。
3. 開啟右上角 **「開發人員模式 (Developer mode)」** 開關。
4. 點擊左上角 **「載入未封裝項目 (Load unpacked)」** 按鈕。
5. 選擇本專案根目錄下的 [`extension/`](../../extension) 資料夾。

## 📋 2. 人工驗收項目與操作步驟

### 驗收項目 1：側欄/底部導覽書籤入口與卡片網格展示 (`/bookmarks`, `BookmarksView.vue`)

- **測試目標**：驗證桌面端側邊欄與手機底部導覽列皆有「書籤」入口，點擊能正確導向 `/bookmarks`，4 欄響應式網格正常渲染。
- **操作步驟**：
  1. 於首頁或任一頁面，觀察桌面端側邊欄（[`AppSidebar.vue`](../../src/components/layout/AppSidebar.vue)）。
  2. 確認在「我的衣櫥」與「衣櫥統計」之間出現 **「🔖 書籤」** 項目。
  3. 點擊「書籤」，觀察網址切換至 `http://localhost:5173/bookmarks`，頁面順暢載入 [`BookmarksView.vue`](../../src/views/BookmarksView.vue)。
  4. 觀察預設卡片網格（Aritzia、Zara、Mango 等商品），以 `4:5` 比例呈現大圖、商品名、品牌/網域與價格。
  5. 滑鼠懸停於卡片時，圖片具備等比放大動畫。
  6. 點擊卡片右上角的外連圖示按鈕（↗），驗證於新分頁開啟商品原始購物網址。
- **預期結果**：
  - 導覽列連結正常高亮，4 欄網格排版美觀，外連跳轉正確。

---

### 驗收項目 2：手動建立書籤與圖片預覽/檔案上傳 (`BookmarksView.vue`, `bookmarks.js`)

- **測試目標**：驗證橫式雙欄表單 Modal（左側大圖、右側輸入）輸入即時聯動預覽，支援輸入圖片網址與電腦本機上傳圖片。
- **操作步驟**：
  1. 進入 `/bookmarks` 頁面，點擊右上角 **「＋ 建立書籤」** 按鈕。
  2. 觀察彈出橫式雙欄 Modal，左側為「尚未加入商品圖片」佔位卡。
  3. 在右側輸入商品名稱（如 `經典喀什米爾針織衫`）與商品網址。
  4. 於「商品圖片」欄位貼上圖片網址（或點擊「選取檔案」由電腦選擇圖片），觀察左側預覽卡片立即呈現等比大圖。
  5. 點擊「▾ 補充更多 (品牌、尺寸、價格等)」，展開品牌、款式/分類、顏色、尺寸、價格、幣別（TWD/USD/EUR/JPY）與備註欄位。
  6. 填寫完成後點擊「儲存書籤」。
- **預期結果**：
  - 左側大圖預覽即時且不失真，表單成功儲存並關閉彈窗，新書籤出現在網格首位，並跳出 Toast 提示「已建立書籤」。

---

### 驗收項目 3：重複商品收藏偵測與二次確認防護 (`bookmarks.js`)

- **測試目標**：驗證當使用者輸入相同網址、款式、顏色與尺寸的商品時，系統能自動攔截並跳出二度確認提示。
- **操作步驟**：
  1. 再次點擊「＋ 建立書籤」。
  2. 輸入與現有書籤相同的商品網址、款式、顏色與尺寸。
  3. 點擊「儲存書籤」。
  4. 觀察瀏覽器跳出二度確認對話框：`您已收藏過相同網址、款式及尺寸的商品，確定仍要儲存嗎？`。
  5. 點擊「取消」：返回表單繼續編輯；點擊「確定」：確認繼續儲存。
- **預期結果**：
  - 防重複機制運作正常，有效防止誤操作重複收藏。

---

### 驗收項目 4：商品詳情檢視、編輯、單件刪除與商品頁外連 (`BookmarksView.vue`)

- **測試目標**：驗證點擊書籤卡片開啟詳情彈窗，展示完整商品資訊，並能直接編輯、刪除或跳轉商品頁。
- **操作步驟**：
  1. 點擊網格中的任意商品卡片。
  2. 彈出「商品詳情」彈窗，左側為商品大圖，右側列出：品牌、價格、尺寸、顏色、款式、來源網域與備註。
  3. 點擊彈窗底部 **「前往商品頁面」** 按鈕，驗證於新分頁開啟該商品原始頁面。
  4. 點擊 **「編輯」** 按鈕，彈窗切換為編輯表單，修改價格（如由 `3990` 改為 `3500`）或備註後儲存，確認網格即時更新。
  5. 再次開啟該商品詳情彈窗，點擊 **「刪除」** 按鈕，在確認對話框點擊確定。
- **預期結果**：
  - 詳情資訊欄位完整對齊，編輯與單件刪除均正確生效並同步更新。

### 驗收項目 5：批次管理模式與多選刪除 (`BookmarksView.vue`)

- **測試目標**：驗證進入管理模式後的卡片勾選、計數統計與批次刪除功能。
- **操作步驟**：
  1. 點擊頂部工具列的 **「管理」** 按鈕。
  2. 觀察按鈕變更為「完成」，各卡片左上角浮現 Checkbox 選取框，且上方出現批次管理橫條，顯示 `已選 0 件`。
  3. 勾選 2 張以上卡片，觀察卡片出現綠色聚焦外框，且管理條即時更新為 `已選 2 件`，「刪除已選」按鈕轉為可點擊狀態。
  4. 點擊 **「刪除已選」**，在確認對話框中確認刪除。
- **預期結果**：
  - 所選之 2 件商品自網格中移除，跳出 Toast 提示「已移除 2 個書籤」，管理模式自動退出。

### 驗收項目 7：Chrome 擴充功能一鍵解析電商與跨分頁同步 (`extension/`)

- **測試目標**：驗證 Chrome 擴充功能在電商商品頁自動萃取標題、圖片、價格、品牌與尺寸，並無縫傳送至 OOTie 書籤頁。
- **操作步驟**：
  1. 確保已於 `chrome://extensions/` 載入 `extension/` 目錄。
  2. 使用 Chrome 瀏覽器開啟任意電商商品頁（例如 UNIQLO 台灣、GU、ZARA、Lativ 或 NET 某商品頁）。
  3. 點擊 Chrome 工具列的 **OOTie 擴充功能圖示**。
  4. 觀察彈出的 600px 雙欄 Popup 視窗：
     - 左側自動載入該商品之主要高畫質照片。
     - 右側自動填入乾淨的「商品名稱」、品牌、顏色、尺寸、價格與幣別。
  5. 點擊彈窗底部的 **「傳送到 OOTie 書籤」**。
  6. 確認擴充功能選取的環境與 `extension/config.js` 設定一致，再觀察 Chrome 切換或開啟至該環境的 OOTie 書籤頁；建立表單應自動帶入商品資料並出現 Toast「已從擴充功能帶入商品資訊」。
  7. 點擊「儲存書籤」。
- **預期結果**：
  - 擴充套件解析精準，跨分頁自動聚焦並預填表單，書籤成功建立。
