# OOTie 人工驗收指南：lan 功能整合 (願望清單與穿搭商品書籤系統、Chrome 擴充功能與 Supabase 同步)

> **文件版本**：1.0.0  
> **建立日期**：2026-09-26  
> **測試對象**：`lan` 分支功能（穿搭商品願望清單/書籤、橫式大圖表單、商品詳情彈窗、批次管理刪除、Chrome 智慧擷取擴充功能、Supabase `ootie_bookmarks` 資料表與 RLS 權限）之功能驗收  
> **技術棧**：原生 HTML5 + CSS3 + 原生 JavaScript (ES6+) + Chrome Extension (Manifest V3) + Supabase (PostgreSQL / Storage)

## 🛠️ 1. 準備工作 (Prerequisites)

在進行人工驗收之前，請確保本地開發環境已備妥：

```bash
# 1. 透過 VS Code Live Server 或靜態伺服器啟動網頁
# 預設網址：http://127.0.0.1:5500/bookmarks.html

# 2. 安裝 Chrome 擴充功能
# 開啟 Chrome 瀏覽器 -> 網址列輸入 chrome://extensions/ -> 開啟「開發人員模式」
# 點擊「載入未封裝項目」 -> 選取專案根目錄下的 extension/ 資料夾
```

## 📋 2. 人工驗收項目與操作步驟

### 驗收項目 1：側欄/底部導覽書籤入口與卡片網格展示 (`bookmarks.html`)

- **測試目標**：驗證桌面端側邊欄與手機底部導覽列皆有「書籤」項目，點擊後進入書籤頁面，4 欄響應式網格正常渲染。
- **操作步驟**：
  1. 於首頁或任一頁面，觀察桌面端側邊欄或手機底部導覽。
  2. 確認在「我的衣櫥」下方出現 **「🔖 書籤」** 導覽項目。
  3. 點擊「書籤」，頁面平滑載入 `bookmarks.html`。
  4. 觀察預設卡片網格（Aritzia、Zara、Mango 等範例商品），以 4:5 比例呈現大圖、商品名、品牌與價格。
  5. 滑鼠懸停於卡片時，卡片圖片具備等比放大動畫。
  6. 點擊卡片右上角的外連圖示（↗），能於新分頁開啟商品原始購物網址。
- **預期結果**：
  - 導覽列連結正常高亮，4 欄網格排版美觀，外連跳轉正確。

---

### 驗收項目 2：手動建立書籤與圖片預覽/檔案上傳 (`bookmarks.html`, `bookmarks.js`)

- **測試目標**：驗證橫式大圖表單彈窗（左側大圖、右側輸入）輸入即時聯動預覽，支援輸入圖片網址與電腦本機上傳圖片。
- **操作步驟**：
  1. 點擊頁面右上角 **「＋ 建立書籤」** 按鈕。
  2. 觀察彈出橫式雙欄 Modal，左側為「尚未加入商品圖片」佔位卡。
  3. 在右側輸入商品名稱（如 `經典羊毛針織衫`）與商品網址。
  4. 於「商品圖片」欄位貼上圖片網址（或點擊「選取檔案」由電腦選擇圖片），觀察左側預覽卡片立即呈現等比大圖。
  5. 點擊「▾ 補充更多」，展開品牌、款式、顏色、尺寸、價格、幣別（TWD/USD/EUR/JPY）與備註欄位。
  6. 填寫完成後點擊「儲存書籤」。
- **預期結果**：
  - 左側大圖預覽即時且不失真，表單成功儲存並關閉彈窗，新書籤出現在列表首位，並跳出 Toast 提示「已建立書籤」。

### 驗收項目 4：批次管理與勾選刪除 (`bookmarks.html`, `bookmarks.js`)

- **測試目標**：驗證進入管理模式後的卡片勾選、計數與批次刪除功能。
- **操作步驟**：
  1. 點擊頂部工具列的 **「管理」** 按鈕。
  2. 觀察各卡片左上角浮現 Checkbox 選取框，且頂部出現管理工具列，顯示 `已選 0 件`。
  3. 勾選 2 張以上卡片，觀察卡片出現醒目外框，且頂部即時更新為 `已選 2 件`，「刪除已選」按鈕轉為可點擊狀態。
  4. 點擊 **「刪除已選」**，在確認視窗中確認刪除。
- **預期結果**：
  - 所選之 2 件商品自網格中移除，彈出 Toast 提示「已移除 2 個書籤」，管理模式自動退出。

### 驗收項目 5：擴充功能安裝引導 Modal 與 Mockup 展示

- **測試目標**：驗證「安裝擴充功能」引導彈窗與操作介面展示圖渲染。
- **操作步驟**：
  1. 點擊工具列上的 **「安裝擴充功能」** 按鈕。
  2. 彈出擴充功能介紹彈窗，包含簡介、Mockup 預覽圖片與「安裝 OOTie 擴充功能」按鈕。
  3. 點擊「安裝 OOTie 擴充功能」按鈕，彈窗關閉並提示安裝指引 Toast。
- **預期結果**：
  - 彈窗呈現完整圖文指引，無破圖或版面溢出。

---

### 驗收項目 6：Chrome 擴充功能一鍵解析電商與跨分頁同步 (`extension/`)

- **測試目標**：驗證 Chrome 擴充功能在電商商品頁自動萃取標題、圖片、價格、品牌與尺寸，並無縫傳送至 OOTie 書籤頁。
- **操作步驟**：
  1. 確保已於 `chrome://extensions/` 載入 `extension/` 目錄。
  2. 使用 Chrome 瀏覽器開啟任意電商商品頁（例如 UNIQLO 台灣、ZARA 或 Lativ 某商品頁）。
  3. 點擊 Chrome 工具列的 **OOTie 擴充功能圖示**。
  4. 觀察彈出的 600px 雙欄視窗：
     - 左側自動載入該商品之主要高畫質商品照片。
     - 右側自動填入乾淨的「商品名稱」、品牌、顏色、尺寸、價格與幣別。
  5. 點擊彈窗底部的 **「傳送到 OOTie 書籤」**。
  6. 觀察 Chrome 自動切換/開啟至 OOTie `bookmarks.html` 頁面，且「建立書籤」表單已自動填入該商品全部資料。
  7. 點擊「儲存書籤」。
- **預期結果**：
  - 擴充套件解析精準，跨分頁自動聚焦並預填表單，書籤成功建立。

---

### 驗收項目 7：Supabase 雲端資料庫持久化、RLS 權限與離線快取

- **測試目標**：驗證書籤資料在 Supabase `ootie_bookmarks` 資料表中的寫入/查詢/更新/刪除，以及在無網路環境下之 LocalStorage 快取備援。
- **操作步驟**：
  1. 建立或修改書籤後，重新整理瀏覽器頁面（F5）。
  2. 觀察所有新增/修改的書籤資料完整保留。
  3. 在離線或無 Supabase 連線金鑰情況下，驗證書籤仍能正常載入與操作（透過 LocalStorage 自動備援）。
- **預期結果**：
  - 資料持久化健全，具備雲端與本地端雙軌高可用性。
